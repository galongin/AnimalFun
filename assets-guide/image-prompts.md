# AnimalFun Image Prompts For ChatGPT

Use these prompts directly in ChatGPT image generation. Paste one full prompt into chat as-is.

## How To Use In ChatGPT

Paste a full prompt like this:

`Create a single image: cute cartoon cow, flat vector illustration, bright cheerful colors, pure white background, centered full body, friendly smiling face, rounded shapes, soft black-and-white patches, small pink nose, simple hooves, child-safe farm animal design, children's educational app asset, no text, no scenery, no props, no extra animals, square composition, PNG-style asset, suitable for 512x512 output.`

If ChatGPT adds backgrounds or extra details, add this sentence at the end:

`Keep the background pure white and include only one animal.`

## Global Style Rules
- Start each request with `Create a single image:`
- Cute cartoon animal
- Flat vector illustration style
- Bright cheerful colors
- Pure white background
- Centered full-body subject
- Friendly child-safe expression
- Simple bold shapes with minimal detail
- High contrast, clean composition
- Consistent educational app asset style for ages 3-8
- Square composition, suitable for 512x512 output

## Optional Negative Guidance

If needed, append this sentence to any prompt:

`Avoid realism, backgrounds, scenery, extra animals, text, logos, watermarks, props, clutter, and scary expressions.`
